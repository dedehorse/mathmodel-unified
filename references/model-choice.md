# 题型与方法选择

先从题目的输入、输出、约束和评价标准判断任务类型，必要时组合方法。下面是候选路线和主要核查点，不代替题面分析，也不保证某方法适合特定题目。

| 主要任务 | 先做的基线 | 增加复杂方法前要核查 |
| --- | --- | --- |
| 机理、物理或几何 | 守恒关系、量纲分析、简化解析式或小规模数值算例 | 单位、坐标系、边界、参数来源和极端情形 |
| 预测与统计推断 | 可解释规则、简单回归或时间/分组基线 | 数据切分单位、信息泄漏、重复测量、类别不平衡与误差区间 |
| 优化与调度 | 明确变量、目标、硬约束，先找可行解 | 可行域、单位、约束遗漏、求解状态、最优性间隙与时间限制 |
| 综合评价 | 核对指标方向，给出透明的归一化与权重基线 | 权重来源、尺度效应、排序敏感性和相关指标重复计入 |
| 多阶段混合问题 | 将子模型的输入输出和误差口径写成接口 | 上游误差传播、参数共享、子问题间逻辑一致性 |

对显著改变答案的题意歧义，先列合理解释并做小算例，不要直接把某个解释写进代码。引入更复杂的模型时，要说明它相对基线解决了什么已观察到的问题；若没有可信改善，保留简单方案。结果报告应分别陈述模型拟合、实际可行性和适用边界。
