# 论文与交付终审

只在论文终审、提交前检查或完整流程收尾时读取。先明确比赛名称、年份和官方文件版本；下面的清单是核查类别，不宣称任何赛事的具体页数或格式数值。

| 类别 | 核查问题 | 证据 |
| --- | --- | --- |
| 题意与模型 | 顶层问题是否全答；假设、变量、约束与实际求解是否一致 | 题面、分析报告、代码 |
| 数值 | 摘要、正文、图表、附录和结果文件是否同口径；关键结论能否复算 | 原始数据、日志、结果表 |
| 图表 | 是否来自真实数据或真实方法；标题、单位、图例、正文引用是否一致 | 图表源文件与 PDF |
| 文献 | 是否真实、确实使用且引用位置正确 | DOI、出版社或原始文献记录 |
| PDF | 是否可搜索、图文清晰、章节完整、表格不越界、无占位符 | 最终版 PDF 与编译日志 |
| 身份与合规 | 是否泄露姓名、学校、账号、文件元数据等赛事禁止的信息 | 官方规则、PDF 属性、附件 |
| AI 使用 | 使用声明与详情、允许范围、人工核验记录是否符合当届规定 | 官方规则与团队记录 |
| 提交 | 文件名、摘要/正文/附录、支撑材料、校验值或提交窗口是否符合规定 | 当届官方提交说明 |

有明确错误时修复并复查受影响部分；缺少证据时标“待核实”，不要用推测补齐。不要将参赛论文上传到未获授权的查重或 AI 检测站点。
